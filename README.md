# Bulgaria Trainer

Тренажёр для подготовки к собеседованию на болгарское гражданство: 22 вопроса с ответами, уроки и проверка себя.

**Открыть:** https://wexwxee.github.io/bulgaria-trainer/

## Что умеет

- Уроки по вопросам и режим «Проверь себя»: все 22 вопроса, 10 случайных или только трудные
- Список «эти ответы повтори» после каждой попытки, история результатов и прогресс
- Работает без интернета: устанавливается на телефон как приложение (PWA)

## Как устроено

Один файл `index.html` без сборки и зависимостей, `sw.js` кэширует приложение для офлайн-режима, `manifest.webmanifest` и `icons/` нужны для установки на телефон. Сайт публикуется через GitHub Pages из ветки `main`.

Запуск локально: открыть `index.html` в браузере или выполнить `python -m http.server` в папке проекта.
